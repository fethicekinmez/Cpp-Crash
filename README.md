# C++ Crash Course

This repository contains a collection of C++ examples demonstrating fundamental concepts and advanced features of the C++ programming language.

## Topics Covered

1. **Basic Concepts**
   - [Arrays and array manipulation](01-Arrays/)
   - [Bitwise operators and their real-world applications](02-Real_Bitwise_Operator/)
   - [Assignment operators](03-Assignment_Operators/)
   - [Relational operators](04-Relational_Operators/)
   - [Logical operators](05-Logical_Operators/)

2. **Preprocessor Directives**
   - [The `#` operator (stringization)](06-The_%23_Operator/)
   - [The `##` operator (token concatenation)](07-The_%23%23_Operator/)

3. **Memory Management & Structures**
   - [Pointers fundamentals](08-Raise_Function/)
   - [Working with structures](09-Pointers_to_Structures/)
   - [Pointers to structures](09-Pointers_to_Structures/)

4. **Object-Oriented Programming**
   - [Namespaces and directives](10-Namespace_with_Directives/)
   - [Classes and member functions](12-Class_Member_Functions/)
   - [Operator overloading](13-Operator_Overloading/)

5. **System Programming**
   - [Signal handling (SIGINT, etc.)](11-Signal_Function/)
   - Process management

## Key Takeaways

- Understanding memory management and pointer manipulation in C++
- Learning object-oriented programming principles
- Mastering preprocessor directives and their uses
- Handling system signals and process control
- Working with operator overloading for custom types

## How to Use

Each directory contains a standalone example focusing on a specific concept. To compile and run any example:

1. Navigate to the desired directory
2. Compile using g++: `g++ main.cpp -o main`
3. Run the executable: `./main`

## Prerequisites

- G++ compiler
- Basic understanding of programming concepts
- Unix-like operating system (macOS, Linux) or Windows with appropriate C++ development environment

## Learning Path

The examples are organized in increasing order of complexity. It's recommended to follow the numbered order of directories for the best learning experience.
